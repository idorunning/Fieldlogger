# App access and reviewer notes

Core camera capture, local journal, notes, collection, milestones and sharing are available without an account. The app opens to the journal; tap **Camera** at the bottom to capture a discovery. Grant Camera and optional foreground Location when prompted. Saved photos remain available offline.

An account is required for upload, multi-device access and optional identification. Reviewers can register a standard email/password account from the account icon, or you can provide a dedicated reviewer account in the Play Console's private App access fields. Do not use your personal account credentials or paste passwords into public listing files. Login does not use a ChatGPT account or browser toolbar.

Automatic identification additionally requires the account's own working OpenAI API key. It is entered under the key icon and saved encrypted on the server. The app does not supply a free key or promise free API usage. Reviewers can test the core photo journal without a key. If full identification must be demonstrated, arrange a dedicated test account with a budget-limited key through private settings and provide those access instructions privately in Play Console.

Native account settings include journal export/import and account deletion. The public deletion URL is https://fieldlogger.co.uk/delete-account; sign in on the website with the same account first, then confirm the password and deletion checkbox.

Suggested Console declaration: **some functionality requires access instructions** because identification and account sync are gated. Explain the freely accessible local journal and the account/key requirement accurately. A reviewer credential has not been created or invented in this pack.
